# Welcome

This invented course follows a group building paper models. All people, events,
measurements and examples are fictional test data.

The group will @highlight{choose materials}, assemble a model and record a result.
Keep **one copy** of each plan and *label the parts* before starting.

::: note Before the session {icon=none}
Read the instructions and leave room on the table for a finished model.
:::

::: checklist
- [ ] Find a clear table
- [ ] Collect paper and tape
- [ ] Read the assembly plan
:::

## Session choices

::: columns
:: Materials
Choose two sheets of paper and one roll of tape.
:: Plan
Draw a small bridge and label its supports.
:: Record
Write down what changed between the first and second models.
:::

# Assembly

::: sequence {style=numbered}
:: Mark
Draw two fold lines on a sheet.
:: Fold
Fold along the marked lines.
:: Stand
Place the model on the table and check both supports.
:::

::: accordion
:: If a support slips
Move the support closer to the centre and try again.
:: If a fold opens
Press the fold flat before adding a small piece of tape.
:::
