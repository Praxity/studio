# Licensing boundaries

- Praxity-authored Studio code and the exported course player use MIT (root
  `LICENSE`, explained in `LICENSING.md`). Earlier Studio versions are also
  available under MIT from 2026-11-21.
- Past terms are preserved in `legal/archive/`. Never edit archived texts.
- Every export ships the MIT licence as `PRAXITY-COURSE-RUNTIME-LICENSE.txt`.
  The Praxity course player in already delivered exports is also available to
  recipients under MIT from 2026-11-21.
- `docs/prax-format/` keeps its own licences: spec CC BY 4.0, examples CC0,
  skills and code MIT.
- Keep third-party notices (fonts, icons, codecs, Typst/MiTeX, SCORM schemas)
  with every package and export.
