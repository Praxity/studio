# Studio 0.2.0 authoring coverage audit

September 21, 2026. Reviewed the current authoring paths against the published grammar,
with particular attention to changes since 0.1.8. This is a targeted audit, not a claim
that every grammar combination has an end-to-end test.

## Findings addressed

| Path | Finding and change |
| --- | --- |
| Card save/reopen | The serializer omitted `layoutMode` when a card also specified its presentation in `layout`. Preserve both; independently test grid, rows, masonry and slides presentations with narrow width. |
| Narrow published blocks | The old browser test manually added narrow CSS classes. Replace it with authored note, quote and card grammar passing through save/reparse and compilation, in small/full preview and both engines. This exposed the card save bug. |
| Slash and Blocks insertion | Both use the shared catalog. No missing recent parameter was found. Add independent selection/save assertions for card rows/media/width, image float, comparison presentation and table controls instead of relying only on generated metadata checks. |
| Compositions | Meeting roles was covered only by generic catalog checks. Verify actual panel selection, item text/list boundaries and outside content after save/reparse. |
| Media cards | Existing browser coverage exercised grid fronts. Add rows, slides and masonry flip fronts, captions, unchanged back ordering, image loading and narrow/wide viewport checks. |
| Table controls | Retain semantic/attribute checks and add computed border, shading and alignment assertions. |
| Design panel | Old tests assumed the Theme section opened by default and referenced a retired Basic control. Navigate the current panel while preserving its color, logo and geometry assertions. |
| Studio preferences | An old menu test read settings through IPC without checking the visible view. Add visible-control changes and restart persistence. This exposed the native Settings menu doing nothing on Welcome; reuse the existing Settings view there. |
| Course/module settings | Check course defaults and a module override remain distinct after reopening. |
| Card narration | Add authored front/back generation through saved sidecar, restart, canonical preview and SCORM assets/playlist. Only provider IPC/audio bytes are simulated; storage, identity, compilation and export are real. |
| Play narration visibility | Existing runtime behavior already requires local enabled audio. Add disabled/script-only cases and narrated-to-unnarrated module navigation, retaining transcript content. |

The Welcome Settings fix passed independent review for focus restoration, controller
lifetime and updates arriving while Settings is closed. Preserve the Welcome subtree
and the update controller during close/reopen; unmount those controllers when the editor
takes ownership.

## Remaining gaps

- Untimed per-item tabs/accordion narration has no exact item target comparable to card
  front/back targets. Timed repeated text can also be ambiguous. Current documentation
  guarantees exact untimed targets for cards only; this is a separate behavior decision,
  not coverage that these tests establish.
- Delayed card-runtime initialization needs an additional deck-introduction cancellation
  check for pause and slide navigation. Existing delayed-runtime coverage exercises a
  non-deck card and turning Follow off.
- Nondefault YAML-only playback settings across presentation-preset changes are not
  comprehensively exercised through the authoring UI.
- The existing browser suite retains WebKit keyboard/zoom automation limitations and
  missing multi-section fixture cases. They remain skipped, not passed.
- Provider synthesis, real LMS resume, native assistive technology and signed installation
  or upgrade require their separate release checks.

The 0.2.0 verification summary is [recorded here](0.2.0-verification.md). The user approved the canonical naming migration for 0.2.0: block `width`,
card/comparison `layout`, image `size`, and column `weight`. The shared grammar projection
serves parser/serializer, authoring tools and runtime defaults; current catalog examples and
public format/help documentation are updated with it.

Independent grammar review also caught and resolved two save/validation defects: fenced code containing its own `width` line could suppress the block width, and malformed YAML defaults could throw during scalar coercion. Authoring review replaced projected-key deletion with shared default normalization; actual Card-control tests retain both image dimensions, including legacy input. Image defaults remain YAML-only. A rating fixture accidentally renamed to `layout: slider` was restored to `style: slider`; the independent parser-fidelity assertion was kept.
