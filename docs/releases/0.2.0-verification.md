# Studio 0.2.0 verification summary

The 0.2.0 candidate was checked for grammar migration, authoring, published HTML,
SCORM packaging, narration, responsive layouts and course styling. The historical
delivery record is retained separately by the maintainers.

To reproduce checks with synthetic content, use `docs/test-fixtures/sample-course-grammar.md`
for parser and renderer coverage and `docs/test-fixtures/authoring-catalog-grammar.md`
for authoring controls, including iconless notes. See the
[coverage audit](0.2.0-coverage-audit.md) for the limits of the completed checks and
the [testing strategy](../context/testing-strategy.md) for current commands.

Automated browser results do not establish live LMS compatibility, signed-install
behaviour or assistive-technology speech. Those require their separate release checks.
